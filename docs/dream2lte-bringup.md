# Порт iOS Galaxy S8 → Galaxy S8+ (dream2lte): первая стадия

**Статус:** подготовлен исходный слой `dream2lte` для SM-G955F/SM-G955FD (Exynos 8895). Это **НЕ готовая проверенная сборка iOS**, не ZIP для прошивки и не полный исходный репозиторий. Изменения вносятся в вашу локальную копию оригинального проекта. Ни одна команда из пакета не прошивает телефон.

Основа: <https://github.com/Floppikrob/ios-galaxy-s8>. Исходный S8 (`dreamlte`) продолжает использовать прежние настройки по умолчанию.

## Что делает пакет

- Добавляет `--device dream2lte` к генерации Apple Device Tree и правильные совместимые строки платформы/дисплея.
- Добавляет отдельный скрипт сборки `tools/dream2lte/make-boot.sh`, использующий оригинальный загрузчик и **ваш собственный** стоковый BOOT.img S8+ (с исходным Samsung DTBH).
- Включает отметку `dream2lte` в загрузчике и **выключает диагностические вызовы S8, которые меняют состояние PMIC, сенсора, DPU и Mongoose**, пока они не проверены на S8+.
- Добавляет локальную проверку структуры BOOT.img и **читающую** ADB-проверку модели/разделов/адреса framebuffer.
- Не пишет в BOOT, USERDATA, EFS и другие разделы и не включает автоматическое прошивание.

## Применение к репозиторию (Linux, Ubuntu, WSL)

```bash
git clone https://github.com/Floppikrob/ios-galaxy-s8.git
python3 /path/to/dream2lte-portkit/apply_dream2lte.py ./ios-galaxy-s8 --dry-run
python3 /path/to/dream2lte-portkit/apply_dream2lte.py ./ios-galaxy-s8
cd ios-galaxy-s8
git diff --stat
python3 -m py_compile tools/mkadt_dreamlte.py tools/dream2lte/*.py
bash -n tools/dreamlte/make-boot.sh tools/dream2lte/make-boot.sh shim/dreamlte/build.sh
```

Патчер проверяет ожидаемые участки исходного кода и отказывается менять неподходящую версию. Для изменённых исходников он сохраняет копии `*.pre-dream2lte.bak`, если их ещё нет. Сборка загрузчика оригинального проекта требует `aarch64-linux-gnu-gcc`, `aarch64-linux-gnu-objcopy` и других средств из инструкции автора.

## Только проверка S8+ из TWRP

Запустите телефон в TWRP, подключите ADB и выполните на компьютере:

```bash
adb devices
python3 tools/dream2lte/preflight.py --json dream2lte-preflight.json
```

Скрипт **не меняет разделы**. Проверьте, что полученные `boot_partition` и `userdata_partition` разные, модель `dream2lte`, а адрес framebuffer при наличии параметра — `0xcc000000`. Отсутствие ошибок **не означает**, что прошивать уже безопасно: адреса ramoops, RAM carve-outs, панель и S-Boot ещё требуют проверки.

Резервная копия BOOT с **этого самого S8+** (чтение раздела, файл сохраняется на ПК):

```bash
mkdir -p backup
adb exec-out 'dd if=/dev/block/platform/11120000.ufs/by-name/BOOT bs=1048576 2>/dev/null' > backup/BOOT-G955F.img
python3 tools/dream2lte/validate-stock-boot.py backup/BOOT-G955F.img
```

Если полученный BOOT.img слишком мал, не содержит DTBH или проверка завершилась ошибкой — остановитесь. Не заменяйте его BOOT.img от S8.

## Подготовка образа (ещё БЕЗ ПРОШИВКИ)

После сборки XNU по исходной инструкции автора поместите Mach-O ядро в `xnu/out/` и запустите:

```bash
bash tools/dream2lte/make-boot.sh \
  xnu/out/kernel.development.a5xelte \
  backup/BOOT-G955F.img \
  dream2lte-probe.img
```

По умолчанию передаются минимальные загрузочные аргументы с `cpus=1`, `sweetfb_native=1` и **без монтирования USERDATA в качестве корня iOS**. Даже при успешном запуске этот диагностический образ не сможет загрузить SpringBoard без файловой системы iOS. Его назначение — сборка и дальнейшая проверка первого этапа, а не готовый релиз.

## Что ещё НЕ подтверждено

1. Совпадает ли на конкретном SM-G955F карта зарезервированной RAM и адреса ramoops с S8 (в загрузчике/XNU жёстко заданы `0x92080000`, `0x92180000`, `0x920ff000`).
2. Оставляет ли S-Boot S8+ дисплей и DECON в совместимом состоянии и совпадают ли фактические параметры панели.
3. Корректно ли XNU использует UFS, GPIO клавиш, PMIC и драйвер сенсора на S8+ (некоторые вызовы специально отключены в первой сборке).
4. Совпадают ли ограничения DMA и адресов памяти S8+ с теми, на которых проверялся порт S8.
5. Загружается ли ядро и userland на **реальном S8+**. Это невозможно проверить без аппаратного теста.

Оригинальный проект применяет патч XNU `0124-dreamlte-s8.patch` под конфигурацию A5XELTE; текущий пакет переиспользует этот слой, но **не гарантирует**, что он подходит для G955F без дальнейшей настройки.

Пакет не содержит Apple iOS/образы IPSW, ядро XNU или оригинальные файлы репозитория. При дальнейших экспериментах может потребоваться полное восстановление устройства; сохраните резервные копии TWRP и BOOT за пределами телефона.
